# Known issues and open points

1. **Audio sliders need a home in the UI.** The AD menu handoff has no Sound tab. Proposal (SPEC §1.3): four sliders (Master, Music, Sounds, Ambience) and a Mute branch at the bottom of Settings → Interface, using the existing kit slider and branch. Needs Art Director / Khalil sign-off before PR 6; the engine works without the UI (defaults 100 %).
2. **Nothing has been tested in a browser yet**: not Chrome, not Firefox, not Safari 18.4+. All checks are offline (Python, ffmpeg, libsndfile). Open points for the first browser run: Ogg Vorbis decode and loop timing in Safari 18.4+ (macOS 15.4 / iOS 18.4), context unlock on iOS, hidden-tab suspend/resume, memory on phones (item 4). The TypeScript in IMPLEMENTATION.md is a design sketch and has not been compiled or run.
3. **Nobody has listened yet.** Every SFX, UI, ambience and music file is original synthesis checked only by measurement (loudness, true peak, DC, tails, seams, spectrograms). Expect a tuning pass by ear (levels per cue, a few timbres). First suspect: UI against menu music. With the bus defaults, clicks sit ~10 dB and hovers ~17 dB under the music (`ui_preview.ogg` shows this). If they get lost in the menus, raise the `ui` bus from −3 to 0 dB. Re-render with `sources/*.py` (SFX/UI/ambience) and `sources/music/*.py` (music).
4. **Music memory: ~67 MB decoded.** A decoded key (6 stems × 14.6 s × 48 kHz × 2 ch × float32) is ~34 MB; the engine keeps the current and the next key (~67 MB) plus the menu loop (~11 MB). SFX/UI/ambience add ~25 MB when all roots are decoded (load lazily, IMPLEMENTATION §3). On phones decode `stress` and `shimmer` only when they first turn on.
5. **Music true peak −1.0 dBTP worst case.** All music layers on, worst key, at 0 dB is −1.0 dBTP (no margin). Decision: keep the `music` bus default at −8 dB, which leaves ~7 dB headroom. If the music is ever played at 0 dB with every layer on, take the pluck layer to −2.5 dB.
6. **Decoder length differences.** ffmpeg's Vorbis decoder (which Chrome also uses) returns −128 to +1013 samples against the file's own length on our one-shots; libsndfile is exact. One-shots therefore end in 10 ms of silence (nothing audible is cut), ambience loops measure exact in both, and music stems carry 100 ms padding with `loopStart`/`loopEnd` set from the sample counts, so a trim of a few samples only shifts phase. Confirm in each browser (ACCEPTANCE §4.3).
7. **`stitchLoop()` is mandatory for music stems** (IMPLEMENTATION §7.3), once per decoded buffer. Without it, bed and bass seams have 20–45 dB more high-frequency coding error (still under −80 dBFS, but measurable).
8. **Level-up plays two sounds.** Both are kept by decision: the SFX `level_up__{KEY}` and `music_levelup_{KEY}` at −6 dB on the same bar. Their pitch content agrees (root, 2nd, 3rd, 5th of the new key), but judge by ear whether it is too heavy.
9. **`music_levelup_{KEY}` files are true-peak capped**, so they sit at −19.0 to −21.2 LUFS instead of −18.
10. **UI preview loudness −19.5 LUFS** (target ~−16): the UI reel is mostly silence between clicks; reaching −16 would need >4 dB of peak limiting, which would misrepresent the levels. The SFX reel is −16.3 LUFS, the music preview −16.0; all ≤ −1.3 dBTP.
11. **SFX preview pad is a stand-in.** `sfx_preview.ogg` was built before the music lane finished; its quiet bed is a simple F Lydian pad, not the Afterglow stems. `music_reactive_preview.ogg` is the real music.
12. **Note texts are matched by regex** (`mix-tokens.json` → `logRules`). If a note's wording changes in the repo, its cue silently falls back to the generic rule of that kind. The classifier test (ACCEPTANCE §3) catches this.
13. **The music spec copy in `sources/music/music-spec.md` predates the merge** in two places, superseded by this package: §11 "Coordination" (all four points are now decided; SPEC §1) and its pointer to handoff SPEC §6. `assets/music/music-spec.json` is current. To re-render music, copy `sources/music/` to a scratch folder as `<dir>/sources/` (the scripts write to `<dir>/stems`, `<dir>/notes`).
14. **Build my PC key.** The studio has no level; it uses F (level 1). Fine by design, but means studio cues never change key.
